Run it yourself Free, runs locally, no API key. Give it patent numbers or an inventor name.

git clone https://github.com/Frozen-In-Flames/patent-portfolio-apis.git
cd patent-portfolio-apis
pip install -r requirements.txt
python cli.py build 10000000 12748198 12748190 --out ./optics-co --title "OpticsCo"
python cli.py build 12754414 12748194 12749956 --out ./photonix --title "Photonix"
python cli.py merge ./optics-co ./photonix --out ./merged --title "OpticsCo + Photonix"
